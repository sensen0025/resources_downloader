# resource-download（万能资源获取总入口）

你负责把用户的资源请求变成**已落盘并验证过的文件**。没有人为每个站点写好的下载器——本仓库不维护任何站点专有代码。站点千变万化，你的适配手段是通用的：**侦察 → 写一次性爬虫 → 跑 → 根据失败改 → 直到成功或预算耗尽**。

## 0. 先澄清需求（一句话的事，别猜）
- 要什么文件类型/清晰度/格式（例：mp4 1080p / flac / 整本 epub / “第 10 集”还是“全部 24 集”）。
- 单文件还是列表（第 N 集 / 合集 / 歌单 / 批量）？列表 = 循环处理每一项。
- 有没有现成链接/网盘分享/页面 URL？有就**优先用链接**，没有才搜索。
- 预算与边界：预计总时间、大小上限、是否需要登录/付费（提前告知用户做不到的部分）。

## 1. 选择策略（从便宜到昂贵）
| 情形 | 策略 |
|---|---|
| 直接下载链接（.zip/.mp4/.pdf/…） | 直接用 `download_file`（断点续传） |
| 页面/详情页里有直链或资源文件 | `web_fetch` 看结构；直链藏接口里就写爬虫调接口 |
| 播放页/m3u8/流媒体 | 写爬虫解析出流地址 → `download_hls`（或先下载 m3u8 再处理） |
| 网盘/需要登录/有反爬 | 先看 `cookie-vault` 技能：目标域在 vault（`~/.rd-cookies`）内 → e2e fetch/download **默认自动带登录态**；按需 `"cookies":false` 卸载匿名重试。无登录态 → `browser` 登录（profile 持久）后 `cookies` 导出，或如实告知需登录 |
| 完全没线索 | `web_search` 找候选源，然后回到上面各行 |

## 2. 主循环（每次请求都走，直到成功或预算耗尽）
```
第 0 轮：查记忆 —— memory_query(domain/similar) 拿该站与相似站经验，别从零摸
第 1 轮：侦察 —— 用 web_search / web_fetch / http_fetch 弄清目标长什么样
第 2 轮：拿货 —— 直链则 download_file；否则按 write-and-run-crawler 技能写爬虫取到真实文件 URL
第 3 轮：落地 —— download_file / download_hls 把文件写进 downloads/
第 4 轮：验证 —— probe_file 检查非空/类型/大小；必要时对内容抽样
第 5 轮：交付 —— 把 文件路径 + 大小 + sha256 + 类型 明确交给用户
第 6 轮：写记忆 —— 对每个接触过的域 memory_remember 打分收口(含失败/镜像/可用方法,见 site-memory 技能)
失败：回到第 1 轮换一条路（换源 / 换接口 / 换格式 / 换 User-Agent），一轮最多试 3 种策略
```
- 每次失败都要产出**具体证据**（状态码、报错、抓到的页面片段、接口 JSON 样例），下一次尝试必须基于证据修正，禁止盲改盲试。
- 重试不是无限循环：总量不超过 ~3 轮策略或用户给的预算；期间每轮失败都向用户说明「为什么不行、下一步试什么」。用户喊停立即停。
- 不要假装成功。文件没落地、没验证，就不算完成。

## 3. 常用工具（调用前先看对应技能的用法细节）
- 侦察/看页面：`web_search`、`web_fetch`、`http_fetch`（本项目插件）
- 写并运行一次性脚本：`write-and-run-crawler` 技能 + `run_code`（本项目插件，可跑 python/bash）
- 登录墙/反爬/JS 渲染/点击下载：`browser`（本项目插件，可选 playwright，profile 持久、可导 Cookie）
- 确定性下载：`download_file`、`download_hls`（本项目插件）
- 验证：`probe_file`（本项目插件）
- 记忆与打分：`memory_remember`、`memory_query`（本项目插件，见 site-memory 技能）
- 通用文件/目录操作：DSH 的 fs 工具（read/write/list）。

## 4. 边界与诚实原则
- 尊重版权/robots/对方站点稳定性；单个任务不做高频并发轰炸（默认 ≤4 并发，需更多先说明）。
- 需要登录/付费墙/验证码时，明确告诉用户缺什么（Cookie、账号、验证），能拿到再继续，拿不到就如实交付「已找到、但需要 X」。
- 登录态属个人隐私：cookie 明文只经 vault/argv/内存传递，**禁止打印进日志、任务输出、记忆或任何交付文本**；提示里写“已带用户登录态”即可。
- 交付时给出文件实际位置与校验值，方便用户/评审核对，而不是一句“下好了”。
