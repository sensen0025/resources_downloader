# 笔趣阁系网文站群

## 定位
大量网文站共用相似模板：`小说首页(/book/<id>) → 目录(/book/<id>/) → 正文(/book/<id>/<n>.html)`。
**站点多、域名换、正文可能有防盗段落与广告注入**。做法=现场爬虫，不沉淀站点代码。

## 资源与格式
正文纯文本（章节聚合目标：整章/整本导出 txt/epub）；常见"第X章"列表意图。

## 访问路径（通用套路，非固定站点）
1. 找书：`web_search "<书名> 小说 目录 最新章节"` → 候选书页（看清是不是目标站、有无"XX下载"假按钮——那常是站内互推，见 write-and-run-crawler）
2. 拿目录：书页解析章节列表 URL（规律通常是 `/book/<id>/<n>.html`），确认是**站群内页**而不是外链
3. 逐章抓正文：`run_code` 一次性脚本批量取（限速/sleep 防频控；去广告标签、留文本段落）
4. 合并：按章节顺序拼 txt（或直接交付目录+正文片段当用户只求章节）
5. 失败迭代：结构变了就现场改（书页 404/防盗码 → 换站群其它镜像站）

## 已知风控
- 站群反爬弱（少 CF），但域名封禁/换站频繁；正文偶有防盗版乱码段（替换词/注水）
- 章节多时控制总量与 sleep；别打爆小站

## 工具速查
```python
# run_code python: 目录页 → 提取 /book/<id>/<n>.html 列表 → 逐章 get → strip 标签
```
下载合并用 `download_file` 不适用（非直链）→ 用 `run_code` 生成 txt 后交付；验证用 `probe_file` 文本。

## 合规
多数网文版权受限：仅限用户已获授权/个人存档范围；别镜像整站、别二次分发。

## 记忆建议
tags：`novel` `mirror` `sitegroup`；methods 记录"该站目录 URL 形态+防盗现象"，失效即更新，不做常驻适配器。
